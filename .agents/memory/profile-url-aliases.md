Preserve both handle-based and ID-based URLs when they refer to the same platform account, especially YouTube channels.

**Why:** The user said, “we kinda need both,” after showing a YouTube handle URL and channel-ID URL for the same channel.

**How to apply:** Group verified aliases under a stable platform account ID rather than discarding one URL. Distinguish proving that two URLs refer to the same channel from assessing whether that channel belongs to the reference artist.
