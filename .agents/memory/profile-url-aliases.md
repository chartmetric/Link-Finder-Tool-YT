---

Preserve both handle-based and ID-based URLs when they refer to the same platform account, especially YouTube channels.

**Why:** The user said, “we kinda need both,” after showing a YouTube handle URL and channel-ID URL for the same channel. They also explicitly approved “1 account · 2 URL aliases” labeling because a flat evidence list looked like separate accounts.

**How to apply:** Group verified aliases under a stable platform account ID rather than discarding one URL. In bulk evidence, show the account count and URL-alias count for each confirmed group and keep both links clickable. Distinguish proving that two URLs refer to the same channel from assessing whether that channel belongs to the reference artist.

Legacy YouTube URL resolution requires a retained provider request/response,
not a guessed correspondence between a custom address and a modern handle.

**Why:** A legacy candidate can resolve correctly to a channel that belongs to
someone other than the catalog artist. Resolving the address must not become
ownership acceptance or permission to spend again.

**How to apply:** Preserve original requested and returned addresses and their
receipt provenance. Keep offline resolution separate from ownership evaluation;
never rewrite immutable historical captures to enable paid recovery.
