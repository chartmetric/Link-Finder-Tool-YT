Prioritize single-URL artist investigations as the primary experience, show shared saved investigations below the input, and show tier 1–3 musician coverage at the bottom. Do not restore the standalone catalog page.

**Why:** The user chose single-artist search history for the table, then explicitly removed the catalog page in favor of tier 1–3 musician statistics on the main page.

**How to apply:** Do not substitute catalog records for investigation history or claim older searches were saved. History begins with newly completed investigations; a stored search snapshot is not approval of candidate links.

Keep existing LLM enrichment coverage separate from this app’s investigation coverage.

**Why:** The user was unsure which data source “LLM links” referred to, so both sources are displayed explicitly rather than silently choosing one or combining them.

**How to apply:** Preserve distinct source labels and do not imply discovered links are officially approved. Match investigations to musician profiles using the trusted reference URL, not a fuzzy artist-name match.
