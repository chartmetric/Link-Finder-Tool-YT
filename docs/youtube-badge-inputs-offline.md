# YouTube badge inputs — offline only

The paused quality review found that all 394 successful metadata receipts omitted
`isOfficialArtistChannel` and `isAutoGenerated`. Their absence is not explicit
negative evidence. Generic `isVerified` does not identify an Official Artist
Channel.

The source normalizer now emits each of these three flags as a boolean only when
the exact source field contains a boolean; otherwise its normalized value is
`null` (unknown). `body.badgeSourceFields` retains each field's own-property
presence and its raw value when present, including explicit null or malformed
values. Missing fields have `{present:false}` with no invented value. The existing
raw receipt digest remains, and legacy alias captures still retain their full
receipt. Source packets are not modified.

These fields survive the capture body, ownership input, outgoing request and
their hashes. Input rules distinguish unknown from explicit false and forbid
using generic verification as an artist badge. A badge alone still cannot
establish ownership. Topic/auto-generated, fan, organization, conflicting Spotify
identity, reused-channel and contradictory-evidence checks remain unchanged.
No numeric acceptance threshold or direct-link acceptance behavior changed.

## Operational boundary

This is an **offline-only proposed input change**, not an activated campaign
change or a measured improvement in model outcomes. No provider/model requests
are needed for validation. Do not replace historical inputs, reuse an answer
against changed input hashes, or patch the frozen campaign runtime. Additional
fields/rules can increase request size; the existing byte-limit hold remains
in force, with no clipping or automatic limit increase.

The paused YouTube campaign must remain stopped. Applying these inputs in a new
runtime, fetching new evidence, comparing model outcomes or resuming paid work
requires separate approval.

## Offline regression command

```sh
node --test scripts/src/youtube-ownership-*.test.mjs
```

The badge-specific fixtures exercise true, false, absent, null and malformed
values, JSON serialization, source preservation, input binding and the existing
ownership protections. They make no provider calls.
